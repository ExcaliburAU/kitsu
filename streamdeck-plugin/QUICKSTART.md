# Stream Deck quickstart (Kitsu)

1. Start Kitsu (AppImage / `npm run desktop`) — API binds `127.0.0.1:33384`.
2. Install plugin:

```bash
npm run streamdeck:install
# or
cd streamdeck-plugin && npm run build
```

3. Restart Stream Deck software.
4. Add Kitsu actions (same UUIDs as Paarrot).

Stock Paarrot Stream Deck plugin also works against Kitsu — same port and routes.
